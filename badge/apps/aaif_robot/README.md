# AAIF Robot

AAIF Robot pairs the AAIF logo with a robot waving beside a Sandbox projects message.

## Usage

Open **AAIF Robot** from the badge menu to see the robot wave its hand beside
the message “Our Sandbox is open for new projects!” Press HOME to return to the
menu. No extra hardware or network access is required.

The app uses only the robot artwork saved as `Pictures\DYII4033.JPG` and the
AAIF logo from [the source blog post](https://aaif.io/blog/isolating-agent-generated-code-with-mcp-and-microsandbox).
